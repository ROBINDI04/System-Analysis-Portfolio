# 🚀 Шпаргалка: Полезные горячие клавиши VS Code

> 💡 **Совет:** Если какая-то комбинация не работает (как было с `Ctrl+Shift+P`), всегда используйте клавишу **`F1`** — она открывает ту же самую палитру команд.

---

## 🎛️ 1. Управление интерфейсом и окнами
*   **`F1`** — Открыть Палитру команд (главный инструмент для поиска любых функций).
*   **`Ctrl + \`** — Разделить экран (Split Editor). Позволяет открыть два файла рядом (например, код слева, предпросмотр справа).
*   **`Ctrl + B`** — Скрыть/показать левую боковую панель (Проводник). Освобождает место для кода.
*   **`Ctrl + P`** — Быстрый поиск и открытие любого файла в проекте по его названию.
*   **`Ctrl + ,`** (запятая) — Открыть Настройки (Settings).

## 📝 2. Работа с кодом и текстом
*   **`Alt + ↑ / ↓`** — Переместить текущую строку (или выделенный блок) вверх или вниз. Идеально для сортировки полей в JSON/YAML.
*   **`Shift + Alt + ↑ / ↓`** — Дублировать текущую строку вверх или вниз.
*   **`Ctrl + /`** — Закомментировать или раскомментировать текущую строку (в YAML и JSON это незаменимо при тестировании).
*   **`Ctrl + D`** — Выделить следующее вхождение того же слова. Удобно, если нужно разом переименовать переменную в нескольких местах.
*   **`Ctrl + Shift + K`** — Удалить текущую строку целиком.

## 🔍 3. Поиск и навигация
*   **`Ctrl + F`** — Поиск по текущему открытому файлу.
*   **`Ctrl + H`** — Поиск и замена по текущему файлу.
*   **`Ctrl + Shift + F`** — Глобальный поиск по всем файлам в папке проекта.
*   **`Ctrl + G`** — Перейти к конкретной строке (например, если коллега на ревью сказал: "посмотри на строку 145").

## 📄 4. Специфичные команды для аналитика
*   **`Ctrl + Shift + V`** — Открыть предпросмотр Markdown в текущем окне (очень удобно для чтения).
*   **`Ctrl + K`, затем `V`** — Открыть предпросмотр Markdown в соседней колонке (бок о бок с кодом).
*   **`Ctrl + S`** — Сохранить файл (делайте это постоянно!).
