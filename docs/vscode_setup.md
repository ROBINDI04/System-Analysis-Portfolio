# 🛠️ Шпаргалка: Идеальная настройка VS Code для системного аналитика

Этот файл содержит быстрый доступ к настройкам и командам, которые мы настроили. 

---

## ⚙️ 1. Файл настроек (`settings.json`)

Чтобы открыть файл настроек, нажмите **`F1`** (или `Ctrl+Shift+P`), напишите **`Preferences: Open User Settings (JSON)`** и нажмите `Enter`.

Вставьте этот блок внутрь фигурных скобок `{ ... }`:

```json
{
    // Автосохранение через 1 секунду после остановки печати
    "files.autoSave": "afterDelay",
    "files.autoSaveDelay": 1000,
    
    // Перенос длинных строк (чтобы не прокручивать экран вправо)
    "editor.wordWrap": "on",
    
    // Автоматическое выравнивание отступов при сохранении
    "editor.formatOnSave": true
}
