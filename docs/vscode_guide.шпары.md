# 🛠️ Шпаргалка системного аналитика: VS Code

Этот документ содержит все ключевые настройки, горячие клавиши и лайфхаки. Держите его под рукой!

---

## ⚙️ 1. Базовые настройки

Чтобы открыть файл настроек, нажмите **F1** (или `Ctrl+Shift+P`), напишите **Preferences: Open User Settings (JSON)** и нажмите `Enter`. Вставьте этот блок внутрь фигурных скобок:

```json
{
    "files.autoSave": "afterDelay",
    "files.autoSaveDelay": 1000,
    "editor.wordWrap": "on",
    "editor.formatOnSave": true,
    "openapi.validate": true
}
```

## 📝 2. Работа с текстом (Markdown) 

Действие	Как сделать
Открыть предпросмотр	Ctrl+K, затем V
Открыть предпросмотр сбоку	Ctrl+K, затем Ctrl+V
Автоматическое оглавление	F1 -> Markdown: Create Table of Contents
Вставить картинку	![Название](diagram.drawio.svg)
💡 Совет: Если вы нарисовали диаграмму в Draw.io, сохраните её в формате diagram.drawio.svg (Файл -> Сохранить как). Тогда она отобразится в Markdown и останется редактируемой.

## 🔌 3. Работа с API (Swagger/OpenAPI) 

Открыть предпросмотр: Нажмите на иконку лупы в правом верхнем углу редактора (рядом с кнопкой разделения экрана), либо F1 -> openapi preview.

Проверка ошибок: Если вы забыли отступ в YAML, VS Code подчеркнет это красной волнистой линией (благодаря настройке openapi.validate).

## 🎨 4. Работа с диаграммами (Draw.io)

Создать схему: Создайте файл .drawio и вставьте XML-код (или рисуйте вручную).

Выравнивание фигур: В настройках Draw.io (шестеренка) включите «Snap to Grid» (Привязка к сетке).

Отключить сетку: Там же можно отключить «Grid», если она мешает восприятию.

Редактировать XML: Нажмите </> в верхней панели (или ПКМ -> «Изменить»), чтобы вставить код.

## ⌨️ 5. Горячие клавиши для скорости

Комбинация	Действие
Ctrl + P	Быстрый поиск и открытие файла по имени
Ctrl + Shift + F	Глобальный поиск по тексту во всех файлах проекта
Ctrl + G	Переход к конкретной строке
Ctrl + \	Разделить экран на две части
Ctrl + B	Скрыть/показать левую панель (Проводник)
Alt + ↑ / ↓	Переместить строку вверх/вниз
Shift + Alt + ↑ / ↓	Дублировать строку
F2	Переименовать файл (или переменную)
