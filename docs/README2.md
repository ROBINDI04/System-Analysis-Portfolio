## 🟢 Упражнение 1: Работа с Markdown (файл `README.md`)

**Цель:** Научиться создавать красивую документацию.
Markdown — это язык разметки, который превращает обычный текст в структурированный документ.

**Последовательность действий:**
1. Откройте файл `README.md`.
2. Напишите текст, используя знаки `#` (для заголовков), `*` (для списков) и `|` (для таблиц).
3. Нажмите `Ctrl + S`, чтобы сохранить.
4. Нажмите `Ctrl + K`, а затем `V` — откроется предпросмотр рядом с кодом.

**Пример таблицы для проверки:**

## 🔵 Упражнение 2: Работа с API (файл `api.yaml`)

**Цель:** Научиться читать и визуализировать спецификации OpenAPI.
YAML — это формат для описания API. Расширение Swagger Editor может превратить его в красивый сайт.

**Последовательность действий:**
1. Откройте файл `api.yaml` (тот, который вы создали последним с длинным кодом).
2. Убедитесь, что файл сохранен (`Ctrl + S`).
3. Нажмите `F1`, введите `openapi preview` и выберите **`OpenAPI: show preview using Swagger UI`**.
4. Справа откроется интерактивная документация с кнопкой `Try it out`.

**Что мы добавили в спецификацию:**
*   Описание эндпоинтов (GET, POST).
*   Параметры запроса (limit, role).
*   Схемы данных (User, NewUser).
*   Коды ответов (200, 400, 500).

## 🟠 Упражнение 3: Создание схем (файл `diagram.drawio`)

**Цель:** Освоить визуализацию архитектуры и бизнес-процессов прямо в редакторе.
Для системного аналитика важно не только писать текст, но и рисовать схемы (BPMN, UML, блок-схемы).

**Последовательность действий:**
1. В левой панели (Проводник) нажмите «Новый файл» и создайте файл с названием **`diagram.drawio`** (обязательно с таким расширением).
2. Откроется пустой холст, похожий на Visio.
3. Перетащите на холст любую фигуру из левой панели, соедините её стрелкой с другой фигурой.
4. Нажмите `Ctrl + S`, чтобы сохранить схему.

**Совет:** Если вы сохраните файл как `diagram.drawio.svg`, то сможете вставлять эту картинку в ваши Markdown-документы, и она будет открываться в любом браузере.
